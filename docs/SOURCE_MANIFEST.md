# Manifiesto de fuentes Investep

Este manifiesto identifica el corpus inicial utilizado para formalizar JJTrade
AI. Los archivos originales permanecen fuera del repositorio y no se modifican.

## Jerarquía de interpretación

1. Criterios explícitos validados por Joan.
2. Masterclass del mentor.
3. Clases específicas de estrategias.
4. Clases básicas y de integración.
5. Preguntas y respuestas.
6. Tips y ejemplos.

Una fuente de mayor jerarquía no elimina silenciosamente otra versión. Toda
contradicción debe documentarse y validarse antes de convertirse en código.
